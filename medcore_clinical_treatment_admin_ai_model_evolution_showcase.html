Architectural Delta Report

2023 Baseline vs. 2026 Production-Grade Generation

State Management
2023 Baseline: Hardcoded static HTML markup. Zero client state; search input and edit buttons have no event handlers.
2026 Production: Centralized reactive state engine recalculating KPIs, adherence rates, filters, and drawers in real time.
Domain Realism
2023 Baseline: Placeholder tokens ("Patient 1", "Condition X", "Medicine Y") with no clinical hierarchy or triage context.
2026 Production: MRN IDs, telemetry vitals (BP, HR, SpO2, Temp), structured oncology/cardiology/neuro protocols, and MAR checklists.
Data Visualization
2023 Baseline: Omitted entirely or left as a // TODO: Add Chart.js here comment stub.
2026 Production: Zero-dependency responsive SVG hybrid bar/line telemetry chart & interactive clickable department donut breakdown.
UX & Accessibility
2023 Baseline: Unstyled default browser table that overflows on mobile viewports and lacks ARIA roles or focus states.
2026 Production: Responsive sidebar/drawer layout, high-contrast semantic status badges, keyboard Escape support, and touch-safe targets.
CRUD Workflows
2023 Baseline: Read-only static rows; no ability to inspect charts, administer doses, log notes, or assign treatments.
2026 Production: Full clinical loop: slide-over MAR dose toggling, physician progress note creation, status transitions, and new treatment modal.
